# Demir Gym

Kadıköy'de modern ekipmanlı fitness salonu. Ağırlık, kardiyo, grup dersleri ve kişisel antrenman. Ücretsiz deneme dersi için bize yazın.

**Durum:** Hayalî örnek site (şablonun klasik düzeni ve 'güç' teması). Bilgiler gerçek değildir.

## Görüntüleme
`index.html` dosyasını tarayıcıda açmak yeterli. Site tamamen statiktir; Netlify, Cloudflare Pages veya GitHub Pages'e olduğu gibi yüklenebilir.

## Düzenleme
Bu depodaki dosyaları elle değiştirme. Site, gizli **site-sablonu** deposundaki `musteriler/demir-gym/ayarlar.json` dosyasından üretilir:

```bash
cd site-sablonu
./depoya-gonder.sh demir-gym
```
